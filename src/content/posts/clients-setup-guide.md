## 客户端分类与选型原则

机场代理客户端主要分为两大类别：

1. **第三方通用开源客户端**：如 **Clash Verge Rev、v2rayN、Shadowrocket（小火箭）、FlClash、Hiddify、Karing**。支持导入各大机场标准的订阅链接（Clash YAML、Base64、VLESS 等），规则分流功能强大，适合希望灵活管理多个机场节点的用户。
2. **机场专属客户端**：由特定机场服务商基于开源内核深度定制。用户通常只需要输入账号密码即可登录，免去了查找和转换订阅链接的烦恼，特别适合新手小白（例如无忧链接等）。

## 2026 各操作系统主流客户端推荐

### 1. Windows 电脑客户端
- **Clash Verge Rev**（推荐首选）：基于 Mihomo (Clash Meta) 内核，界面现代美观，支持智能分流与一键开启 TUN 虚拟网卡模式，全面支持 VLESS、Hysteria2 等新协议。
- **v2rayN**：经典的 Windows 客户端，支持 Xray 与 sing-box 双核心，多协议支持最全面，适合进阶极客管理复杂节点。
- **FlClash**：基于 Flutter 开发的跨平台现代客户端，内存占用低，界面简洁流畅。

### 2. macOS 苹果电脑客户端
- **Clash Verge Rev (Mac 版)**：提供 Apple Silicon (M 系列芯片) 与 Intel 架构独立原生安装包，体验与 Windows 端高度一致。
- **Surge Mac**：macOS 平台顶级网络调试与分流代理神器，功能强大且稳定，但为专业付费软件。

### 3. iOS 苹果手机与 iPad 客户端
- **Shadowrocket（小火箭）**：iOS 平台最经典的规则代理客户端，功能强大、省电稳定，支持直接导入各种通用订阅。
- **Stash**：iOS 上的 Clash 规则代理神器，完整兼容 Clash YAML 配置文件与策略组切换。
- **Quantumult X（圈 X）**：功能丰富，支持高级脚本与网络重写。

### 4. Android 安卓手机客户端
- **v2rayNG**：安卓端装机必备的经典工具，协议覆盖广，更新频繁。
- **FlClash / Clash Meta for Android**：支持现代图形界面与丰富的策略分流规则。
- **Hiddify**：跨平台新兴多协议客户端，支持多合一订阅与自动优选节点。

### 5. OpenWrt / 软路由客户端
- **OpenClash**：基于 Mihomo 内核的软路由神器，能够实现全屋设备透明代理、局域网按 IP 分流。
- **PassWall2**：多核心支持，对复杂的策略分流与备用节点故障转移提供了极佳支持。

## 通用 3 步订阅导入教程

无论您使用哪款第三方客户端，订阅导入的底层逻辑完全一致：

```
步骤一：复制订阅地址
登录您购买的机场后台（如光速云、暮光加速等） -> 找到「快速导入」或「一键订阅」 -> 复制 Clash / VLESS 订阅 URL。

步骤二：粘贴至客户端
打开客户端配置管理 -> 点击「新建配置 / 从 URL 导入」 -> 将复制的订阅链接粘贴进输入框并命名。

步骤三：更新并选择节点
点击「更新 / 保存」 -> 等待节点列表拉取完毕 -> 在「代理 / 节点列表」中选择一个低延迟节点 -> 开启系统代理或 TUN 模式。
```

## 常见报错与排查指南

- **订阅更新显示 0 节点或 Network Error**：检查订阅链接中是否包含多余空格；部分老旧客户端可能需要机场提供 Clash YAML 格式转换。
- **网页能打开但系统应用无法连网**：在客户端设置中开启 **TUN 虚拟网卡模式**，即可接管系统全局流量。
- **ChatGPT 报错 Access Denied**：说明当前节点使用的出口 IP 被 OpenAI 屏蔽，建议在代理组中切换为香港、日本或新加坡的原生落地专线节点。
